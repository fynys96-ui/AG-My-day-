# ارتقِ كل يوم — Quest Edition V5

تحديث على V4، لا يمس مفاتيح بيانات V4 (`my-day-ag-v2` وبيانات V4)، ويضيف بيانات تخطيط منفصلة في `irtaqi-quest-brain-v5`.

## المميزات
- ترتيب أولويات قابل للتفسير، أولوية الصلاة حسب وقتها خارج التنافس على XP.
- خطة يومية حسب الوقت والطاقة والاستراحة؛ لا تعدل التقويم تلقائيًا.
- أهداف بمراحل قابلة للتأشير، وتعديل مدة وأهمية وموعد كل مهمة.
- نقل مهام فائتة من الأيام المسجلة، مع عدم مضاعفة XP.
- إحصاءات بسيطة حسب يوم الأسبوع من بيانات الإنجاز المسجلة.
- حد XP للمهام الجديدة (5، أو 3 للمهام المتكررة). لا تغير أرصدة V4 السابقة.
- تصدير/استيراد V5 متوافق مع نسخ V4 السابقة.

## حسابات المستخدمين
هذا الإصدار **لا ينشئ حسابات متعددة أو تسجيل دخول عامًا تلقائيًا**. يظل الوضع الافتراضي بيانات محلية منفصلة لكل متصفح/جهاز، مع واجهة مزامنة Supabase الاختيارية الموجودة من V4. لاستضافة حسابات مستقلة عبر الأجهزة يجب إنشاء مشروع Supabase وإعداد Auth + RLS لكل user_id والتحقق من صلاحيات السياسات؛ لا تنشر service_role في المتصفح.

## التحديث
1. صدّر نسخة احتياطية من التطبيق الحالي.
2. ارفع ملفات هذا المجلد إلى جذر مستودع GitHub Pages بدل الملفات القديمة.
3. افتح الموقع وتحقق من تبويب 🧠 التخطيط الذكي.
4. عند استخدام جهاز جديد استورد نسخة احتياطية، أو جهّز Supabase والمزامنة الاختيارية.

## القيود
- خوارزمية الأولويات قاعدة حسابية مقترحة وليست ذكاءً اصطناعيًا.
- التعلّم يعرض معدلات الإنجاز المسجلة حسب أيام الأسبوع؛ لا يتنبأ بمواعيد التركيز بدقة من دون تسجيل وقت التنفيذ.
- المزامنة ليست تلقائية بعد؛ الرفع والاستعادة يدويان عبر Supabase.
- لا توجد اختبارات متصفح شاملة أو ضمان لإشعارات الخلفية.
