🕌 مواقيت الصلاة التلقائية

جلب المواقيت من خدمة AlAdhan عند الاتصال بالإنترنت، بحسب المدينة والدولة وطريقة الحساب التي تختارها. راجع المواقيت مع جهتك المحلية.

☁️ مزامنة Supabase الاختيارية

المزامنة ليست تلقائية قبل إعداد مشروع Supabase خاص بك. لا تضع مفتاح service_role هنا. استخدم فقط مفتاح publishable/anon مع تفعيل RLS وتسجيل الدخول.

الاستعادة تستبدل البيانات المحلية بعد تأكيدك. أجرِ نسخة احتياطية قبل المزامنة. خطوات SQL الآمنة في README داخل الملف المضغوط.

🔔 التنبيهات الذكية

الإشعارات تعمل عند منح الإذن وأثناء فتح التطبيق فقط. إشعارات الخلفية المضمونة تحتاج خادم Push أو تطبيقًا أصليًا. اضبط أوقات الصلاة حسب مدينتك وتاريخك؛ لا يتم حساب المواقيت تلقائيًا.

🕌 مواقيت الصلاة (إدخال يدوي)

☁️ النسخ الاحتياطي والبيانات

بياناتك محفوظة على الجهاز. التزامن السحابي التلقائي غير مفعّل حاليًا، لكن تقدر تنقل بياناتك بأمان باستخدام ملف احتياطي.

احتفظ بالنسخة الاحتياطية خارج المتصفح قبل مسح بيانات Chrome أو تغيير الهاتف. الاستيراد يستبدل البيانات الحالية بعد التأكيد.
